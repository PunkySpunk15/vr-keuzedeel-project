# The New Sheriff

The New Sheriff is a VR Game made for my VR subject in school (ROCMN Software Developer). It was made in Unity and I used C# for the scripts. Most assets I used are free and from the internet, some like the pictures I used for the characters in my game were made by me by photographing my characters with a green screen in school. I customised, edited and combined a few assets to create a unique and more fitting design.
